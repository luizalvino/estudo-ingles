# Spec Delta

## Purpose

Aula de second conditional do básico ao avançado, com explicações em português, exemplos traduzidos e exercícios com correção.

## ADDED Requirements

### Requirement: Lesson teaches the basic form first
The system SHALL present the second conditional form (if + past simple in the condition, would + base verb in the result) before any advanced variation.

#### Scenario: Student starts the lesson
- **WHEN** the student reads the first sections
- **THEN** the system shows the structure, an affirmative example with translation, and the contraction `would` → `'d`

### Requirement: Lesson teaches core uses with examples
The system SHALL explain each core use — hypothetical present/future situations, advice with "If I were you", and dreams/wishes — with at least one translated example each.

#### Scenario: Student studies the uses section
- **WHEN** the student reaches a use subsection
- **THEN** the system shows the explanation in Portuguese plus an English example with its Portuguese translation

### Requirement: Lesson covers advanced variations
The system SHALL cover `were` for all persons, `could`/`might` in the result clause, and `unless` with second conditional meaning.

#### Scenario: Student reaches the advanced section
- **WHEN** the student reads the advanced section
- **THEN** the system shows each variation with a translated example and a note on the meaning change

### Requirement: Lesson includes exercises with answers
The system SHALL provide at least one exercise per section level (basic, uses, advanced) where the student can check the correct answer. Exercises SHALL include the book's Unit 11 formats: matching, sentence rewriting, and verb-form completion.

#### Scenario: Student practices
- **WHEN** the student completes an exercise and requests the answer
- **THEN** the system reveals the correct answer with a brief explanation in Portuguese

### Requirement: Lesson covers mixed conditionals and formal inversion
The system SHALL explain mixed conditionals (past condition with present result, and present condition with past result) and the formal inversion form (`Were` + subject + `to`-infinitive), each with a translated example.

#### Scenario: Student reaches the mixed and formal section
- **WHEN** the student reads the mixed and formal section
- **THEN** the system shows each pattern with an English example and its Portuguese translation

### Requirement: Lesson covers alternative conditional structures
The system SHALL present `unless`, `provided/providing`, `supposing`, `if it weren't for`, and `if...were to` with second conditional meaning, each with a translated example.

#### Scenario: Student reaches the alternatives section
- **WHEN** the student reads the alternatives section
- **THEN** the system shows each structure with an English example and its Portuguese translation

### Requirement: Lesson contrasts first and second conditional
The system SHALL include a comparison showing first conditional (real possibility) versus second conditional (hypothetical), with paired examples.

#### Scenario: Student confuses the two conditionals
- **WHEN** the student reads the comparison section
- **THEN** the system shows the paired examples and states when to use each one
